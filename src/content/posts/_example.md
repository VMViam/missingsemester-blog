This file exists so the shape of a post is written down. It is a `draft`, so it
never appears on the site.

Frontmatter is validated at build time:

- `title` — required, string
- `date` — required, any date the parser accepts
- `description` — optional, one line, used for the index and the meta tags
- `tags` — optional array of strings
- `draft` — optional boolean, `true` keeps the post off the site
